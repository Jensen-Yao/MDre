# MDre

![MDre](assets/mdre-icon.png)

**轻量、直接、本地优先的 Markdown / HTML 阅读器。**

[产品首页](https://jensen-yao.github.io/MDre/) · [下载 Releases](https://github.com/Jensen-Yao/MDre/releases) · [English](readme.en.md)

## 产品定位

MDre 面向 Windows、Android 和 HarmonyOS，帮助你快速打开、阅读、编辑和导出本地文档。

本软件参考了市面上常见 MD 阅读器软件的功能取舍，比如 Obsidian 的基础阅读功能，开发出一个更轻量、更直接的日常阅读工具。

## 功能

- 打开 MD、Markdown、TXT、HTML、JSON 和 XML 等常见文档。
- 支持 Markdown 表格、任务列表、删除线、代码高亮、KaTeX 公式、Mermaid 图和本地图片。
- 支持 HTML 安全过滤，禁止 script、iframe、object、embed 和 base 等危险标签。
- 支持标题导航、折叠层级、全文搜索、高亮、搜索替换和最近文件。
- 支持预览态基础编辑、源码编辑、撤销重做、保存、打印以及 Word/PDF 导出。
- JSON/XML 自动进入结构化阅读模式，可按层级浏览、折叠和排序。
- 支持 Windows、Android、HarmonyOS 的文件管理器打开和系统分享打开。
- Pro 版本支持可配置的 AI、翻译和模型 API；基础阅读不依赖账号。
- 本地优先、无遥测，适合离线阅读和日常文档处理。

## 隐私

MDre 的基础阅读功能以本地文件为中心，不要求注册账号，也不上传文档内容。使用翻译或 AI 功能时，只有在用户主动配置并发起请求后，选中文本或请求内容才会发送到所配置的服务商。
