## 产品定位

MDre 是一款面向 Windows、Android 和 Linux x64 的轻量级 Markdown / HTML 阅读器，用于快速打开、阅读和简单编辑本地文档。

本软件参考了市面上常见 MD 阅读器软件的功能取舍，比如 Obsidian 的基础阅读编辑功能，开发了一个更轻量、更直接的日常阅读工具。

## 功能特点

- 支持 Windows 桌面版和 Android 版。
- 支持打开`.markdown` `.txt` `.html` `.htm`
- 支持 Markdown 表格、任务列表、代码高亮、公式、Mermaid 图等常用内容预览。
- 超出普通katex公式渲染，实际使用可渲染复杂公式的能力 超过 VScode 原生渲染
- 支持 HTML 静态页面预览，并识别常见 Mermaid 片段。
- 支持文档内搜索、标题导航、最近文件和页面颜色切换。
- 本地优先，无账号要求，无遥测。     
- 安卓端的极致轻量化，Android 版本安装包仅约 5MB。
